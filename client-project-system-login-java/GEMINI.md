# Diretivas do Gemini para este Projeto

- **Sempre incluir o seguinte co-autor em todos os commits do git:** `Gemini CLI <gemini-cli@users.noreply.github.com>`
- **Sempre escrever as mensagens de commit no idioma português.**
- **Nunca deletar branches**, a menos que seja explicitamente solicitado.
- **Nunca realizar commits, `git add` ou comandos do Git sem a solicitação/permissão explícita do usuário.**
